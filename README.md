# Anti-Fraud Text Shield

基于 PyTorch 2.0 框架的文本安全检测系统，聚焦反诈数据安全与涉诈行为拦截两大核心场景，提供从数据合规处理到实时拦截的全链路能力。

## 项目背景

### 核心痛点

| 痛点 | 解决方案 |
|------|----------|
| 涉诈文本形态多变（新型话术、伪装正常交流），人工识别效率低、漏判率高 | 多维度正则规则库（12 类话术特征词、8 种虚假链接格式、6 类诈骗账号标识）+ TextCNN 模型融合判决 |
| 反诈数据含大量敏感信息（手机号、身份证号），处理过程中易发生隐私泄露 | 预处理环节自动脱敏 5 类隐私字段（手机号/身份证/银行卡/邮箱/IP），脱敏后方进入后续分析 |
| 公益反诈工具门槛高，非技术人员（志愿者、社区工作者）难以操作 | 交互式控制台，支持粘贴文本和文件导入两种输入方式，全离线运行，无需配置环境 |
| 开源反诈工具缺乏安全管控设计，易被滥用 | AES-256-GCM 数据加密、管理员权限校验、路径遍历防护、代码注入检测、异常操作监控告警 |

## 核心逻辑流

```
数据输入 ──→ 预处理 ──→ 检测 ──→ 安全管控 ──→ 输出
  粘贴文本       隐私字段脱敏     正则规则引擎      实时加密        放行
  文件导入       数据清洗         TextCNN 模型      加密日志        拦截 + 理由
```

### 处理流程

1. **数据输入**：支持本地文本文件导入、实时复制粘贴文本两种输入方式，无网络依赖，所有数据仅在本地流转
2. **预处理**：自动识别并脱敏手机号（11 位数字）、身份证号（18 位含 X）、银行卡号、邮箱、IP 地址等隐私字段，确保数据处理全程合规
3. **推理检测**：正则规则库特征匹配 + TextCNN 模型分类双重校验，判断文本是否含涉诈信息
4. **安全管控**：实时 AES-256-GCM 加密检测日志；命中涉诈特征时自动返回拦截提示，记录操作日志
5. **输出**：正常文本直接放行；涉诈文本显示拦截理由（如"含'无抵押低息贷款'涉诈特征词"），支持加密日志本地导出，无任何数据自动上报

## 公开仓库说明

- 本仓库面向公开演示，核心检测规则通过本地 `compliance/rules_payload.py` 文件加载（已加入 `.gitignore`，不上传）
- 示例文本中的手机号、证件号、邮箱、IP 与高风险话术均已做脱敏或占位处理
- 运行生成的密钥、日志、训练模型、缓存文件均默认不纳入版本控制

## 快速使用

### 环境要求

- Python >= 3.8
- PyTorch >= 2.0.0
- pycryptodome >= 3.15.0
- jieba >= 0.42.1
- numpy >= 1.24.0

### 安装依赖

```bash
pip install -r requirements.txt
```

### 交互式扫描（推荐）

启动后可通过菜单切换粘贴文本输入、文件导入或演示样本：

```bash
python scripts/console.py
```

三种模式：
- **粘贴文本** — 输入完成后按 Ctrl+D（Linux）/ Ctrl+Z（Windows），立即检测
- **导入 .txt 文件** — 逐行扫描文件内容
- **演示样本** — 内置 6 条测试文本

### 完整功能演示

```bash
python scripts/demo.py
```

顺序展示：安全访问校验 → 输入注入检测 → 路径遍历防护 → 隐私字段脱敏 → 涉诈规则扫描 → AES 加解密 → 模型推理 → 实时拦截判决 → 异常操作监控告警。

### 综合测试

```bash
python tests/run_tests.py
```

覆盖测试项：隐私过滤、规则引擎、加密模块、安全防护、拦截器集成、异常监控、准确率评估（共 7 项，200 条混合语料）。

### 模型训练

```bash
python scripts/train.py
```

使用 TextCNN 网络在合成语料（600 涉诈 + 400 正常）上进行训练，模型自动保存至 `models/fraud_model.pt`。

### 数据加密演示

```bash
python scripts/encrypt_data.py
```

生成 AES-256-GCM 密钥，对反诈特征数据进行加密存储与解密验证。

## 模块详情

### 反诈数据合规处理模块

- 12 类涉诈话术特征词（冒充执法部门、投资理财、贷款、刷单、杀猪盘、冒充客服、虚假中奖、赌博、传销、钓鱼链接、虚假招聘、情感诈骗）
- 8 种虚假链接格式（短链接跳转、IP 地址直连、仿冒域名、免费托管域名、编码混淆、@符号混淆、过多子域名、非标准端口）
- 6 类诈骗账号标识（QQ 引流、微信引流、境外社交账号、银行卡号、虚拟货币地址、异常手机号）
- 自动识别并脱敏手机号、身份证号、银行卡号等隐私字段

### 反诈数据加密防护模块

- AES-256-GCM 认证加密，提供防篡改能力
- 密钥通过外部文件注入，代码中无任何硬编码密钥
- 支持字符串级和文件级加密/解密

### 涉诈信息实时拦截模块

- TextCNN 轻量文本分类模型，支持 `torch.compile()` 即时编译加速
- 规则引擎 + 模型概率双维度综合判定
- 检测日志明文与加密双写存储
- 纯离线运行，禁用所有网络上报功能
